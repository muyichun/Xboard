# 即享云客户端长期登录

## 接口与兼容性

- 新增 `POST /api/v1/passport/auth/clientLogin`，请求字段仍为 `email`、`password`，复用 `AuthLogin` 校验和 `LoginService` 密码校验、错误次数限制、禁用账号检查及登录 hook。
- 普通账号返回原有 `data.auth_data`（Bearer 令牌）、`data.token`（现有订阅令牌）、`data.is_admin`，不重置订阅令牌，也不修改套餐或订阅接口。
- 客户端令牌不设置 `expires_at`；现有 `config/sanctum.php` 的全局 `expiration` 为 null。后续如配置全局期限，仍会影响这些令牌。
- 管理员或员工使用此入口返回 HTTP 403，不创建令牌。原网页登录、注册等调用保持一年期限，不受本次修改影响。
- `JX Cloud ` 令牌名称只用于识别会话，并不认证调用者一定来自官方软件；任何通过账号密码校验的普通用户都能调用此入口。
- 当前 macOS 和 Android 客户端依赖此路径；若回退服务端，须同步让客户端使用原登录入口，并接受一年期限。

## 会话与部署范围

没有数据库迁移。旧令牌期限不会被回溯修改，需重新登录才会签发新令牌；令牌仍可通过现有会话管理撤销，不是不可撤销凭据。客户端本地退出不等同于服务端撤销全部会话。

2026-11-05：本次仅在北京开发仓库提交代码，不重建运行容器、不部署生产。当前运行镜像中的旧长期登录入口尚未包含本次管理员／员工限制；该限制需按既有构建发布流程部署后生效。已经签发的令牌不会因代码提交自动失效。
