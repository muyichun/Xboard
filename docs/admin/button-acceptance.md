# 新管理端按钮验收

开发机上的 Chromium 通过真实管理页面操作。测试使用独立的 Laravel、SQLite、Redis 和本地邮件日志驱动，账号、订单、支付渠道和节点均为临时数据。旧版中文菜单的对照版本为 `public/assets/admin` 提交 `ef5f43d`。下面列出实际操作及其判断依据。

| 菜单 | 浏览器操作与核验 |
| --- | --- |
| 仪表盘 | 切换收入金额与笔数，调整日期与两组流量排行范围，打开待处理工单和佣金，刷新队列，打开失败任务列表、翻页并查看详情。 |
| 系统配置 | 站点、安全、订阅、邀请佣金、用户端外观、节点通信、邮件、Telegram 和客户端版本各修改一项并回读。生成并回读节点通信密钥，切换验证码服务及启用状态，保存六种订阅模板并回读内容。邮件模板插入变量、预览草稿、保存、发送测试邮件、恢复默认。 |
| 插件管理 | 搜索与类型页签，查看文档，上传测试插件，安装、配置保存回读、启用、停用、升级、卸载和删除。分别检查已启用插件从本地新版文件升级，以及已停用插件通过 ZIP 升级后的状态。通过菜单演示进入 CRUD 演示，新增、编辑、删除一条示例记录。 |
| 主题配置 | 上传含两张预览图的测试主题，编辑配置并重新读取，预览上一张、下一张和指定图片，启用后核对当前主题，再切回原主题并删除测试主题。 |
| 公告管理 | 添加、编辑 Markdown 和标签，切换展示和弹窗，检查普通用户实际收到的公告及弹窗。拖动排序并回读，最后删除。 |
| 支付配置 | 通过真实 EPay 插件字段添加渠道，编辑后按分核对固定手续费，核对渠道参数，复制通知地址，反复启停，调整顺序并回读，删除渠道。另测连续点击、保存失败后重试、分页以及开关操作是否保留焦点。 |
| 知识库管理 | 创建文章、编辑正文、预览、保存并回读详情，切换显隐、按分类筛选、拖动排序、删除。 |
| 服务器管理 | 创建、修改名称或备注、切换启用状态；查看和复制安装命令、查看及重置认证令牌、关联已有节点、新建本机节点、启停与取消关联。查询 1、6、12、24 小时负载历史，删除测试服务器。 |
| 节点管理 | 从添加表单分别保存 11 种协议，核对协议和端口。编辑地址，设置分时倍率、生成 Reality 和 ECH 密钥、生成 Mieru Traffic Pattern、载入 AnyTLS 默认规则。测试单节点显隐、复制、流量重置、排序和删除。跨页选中两条节点，逐项测试批量显示、隐藏、启用、停用、配置、重置流量和删除，同时检查未选节点。 |
| 权限组管理、路由管理 | 分别新建、编辑、保存回读和删除，检查编辑分组默认展开。路由用带逗号的正则和多行匹配规则验收，切换动作并核对目标值。 |
| 套餐管理 | 创建与编辑、快捷添加权限组、使用说明模板、自动填价和清空价格。显示、新购、续费三个开关分别双向切换并回读。勾选同步用户后检查已分配账号的流量额度和权限组，保存排序、删除套餐。 |
| 订单管理 | 分配两张测试订单，核对月付周期筛选能找回刚分配的订单，查看详情，分别取消与手工标记已支付，回读订单状态。审核有待确认佣金的测试订单。 |
| 优惠券管理 | 创建、从金额优惠改为比例优惠、保存回读、双向启停、操作有效期预设、批量生成并下载 CSV、删除单券。 |
| 礼品卡管理 | 新建通用、套餐和盲盒模板，编辑模板并禁用及启用。批量生成两条码，检查 CSV 内含这两条码，编辑使用次数、变更状态、按批次导出并核对 TXT 内容，删除码和模板。打开使用记录和统计数据。 |
| 用户管理 | 创建单个及批量账号、下载账号 CSV、编辑并回读、查看详情、复制订阅链接、重置 UUID 和订阅令牌、分配订单、打开邀请/订单/流量记录、重置流量和删除测试用户。分别用已选、筛选、全部范围导出、发邮件、封禁；用下载内容、邮件日志、账号状态及会话失效检查实际范围。 |
| 工单管理 | 打开会话、收起和展开工单列表、查看用户信息与流量记录、跳转到该用户的订单、回复、确认关闭、再从已关闭页签查回。 |
| 流量重置日志 | 在用户页提交手动重置，打开重置历史与统计，按条件筛选、导出日志并核对下载内容。 |
| 数据报表、运行状态 | 切换报表类型、下载有明细的报表。打开队列统计、队列负载、进程管理、失败任务及运行状态。 |

共用列表另测筛选与清除、搜索重置、显示列、列排序、分页和每页数量。支付列表在浅色及深色主题下反复将鼠标移入、移出同一行以及相邻行的编辑和删除按钮，比较按钮外区域的像素、表格底色和控件坐标。其余菜单逐页移动鼠标检查布局。移动端使用 390px 宽度检查菜单导航和溢出。

## 本轮修复

- 鼠标移入按钮时，表格行和右侧固定操作列保持原底色。主要按钮保留边缘反馈，图标按钮用前景色反馈，当前操作的按钮、同行其他内容及焦点位置保持稳定。
- 已停用和已启用的插件升级后分别保持原状态。Mieru 节点可以留空 Traffic Pattern，也可以生成后再保存。
- 修复礼品卡模板编辑时奖励和领取限制丢失的问题。回归覆盖余额、赠送套餐、盲盒、邀请奖励比例和每人领取上限。历史上已被覆盖的模板需要按原配置补回缺失的奖励。
- 礼品卡的“统计数据”和流量重置日志的“导出日志”采用旧版按钮名称。
- 修复管理员点击“运行状态 → 进程管理”收到 403 并被退回登录页的问题。这个只读接口使用面板管理员鉴权，游客和普通账号仍返回 403。
