## 2026-11-25 功能按钮复核

对照旧版中文构建与新版的 18 个一级菜单页面，核对工具栏、行操作、筛选、排序和主要设置入口。条件按钮结合隔离数据和代码检查。例如，工单关闭后不再提供关闭操作，插件的升级按钮取决于本地版本。另将旧版请求封装中可直接提取的 115 组固定方法和路径与 Laravel 注册路由交叉核对，均有匹配。包含用户 ID 的流量历史路径另由接口回归覆盖。

| 入口 | 复核结果 |
| --- | --- |
| 公告、知识库、套餐和节点 | 列表展示开关统一为绿色睁眼、灰色闭眼。公告另有弹窗开关，与旧版和内置用户主题使用的“弹窗”标签同步，其他标签正常保留。新建内容默认隐藏，编辑正文或节点配置时保留列表状态。 |
| 服务器管理 | 行内提供详情、编辑和删除。编辑页展开基本信息及安装与认证，详情页提供节点关联和负载历史。列表与详情每 15 秒读取上报快照，采样时间与心跳分别展示。 |
| 插件管理 | 类型页签读取后端定义，空分类也能打开。有说明文档的插件可直接查看文档。升级、卸载和删除按插件状态展示并需要确认。 |
| 订单管理 | 已完成、有佣金且待确认的订单可以审核。提交审核时重新核对状态；另一位管理员已经处理过的订单会提示刷新。 |
| 其他页面 | 仪表盘日期和金额切换、用户和订单操作菜单、工单工作台、礼品卡四个页签、设置和邮件模板等入口见上表。节点编辑字段按分组展开，可滚动编辑。支付启停通过列表绿/灰开关设置，支付列表支持 ID 排序和分页，业务显示顺序从“调整排序”保存。 |

## 数据正确性

- 金额编辑按元，优惠券/礼品卡/支付固定手续费等接口仍使用分；流量编辑的 GB 与字节在明确边界转换。
- AnyTLS padding 和路由匹配按行分割，保留行内逗号。Mieru 随机流量配置使用旧版 protobuf 范围编码。编辑节点合并未知嵌套字段，避免扩展参数丢失。
- Xboard-Node 按配置的上报周期采集 CPU、内存与根文件系统的磁盘占用。服务器列表读取最近一次上报，历史图读取带时间戳的采样记录。超过 5 分钟的读数带有提示，缺少容量或网速数据时历史图留空。
- 订单旧周期筛选转换为当前存储周期。礼品卡空有效期保持不限时，补全码/邮箱查询、禁止套餐条件及旧邀请比例读取。活动加成只倍乘数量奖励，不改变套餐 ID 或比例。
- 礼品卡状态遵循后端枚举：`2` 为过期，`3` 为禁用，不复制旧语言包中颠倒的文案。

## 验收边界

自动化使用隔离 Docker 网络、独立 SQLite/Redis、`.invalid` 测试账号，覆盖真实 API 和 Chromium 表单保存回读。运行方式见 [重写与验收](rewrite.md)。页面对照不等同于逐像素一致；本次保留既有技术栈，以恢复功能和操作习惯为验收目标。

外部 SMTP 实际投递、真实支付回调、Telegram Webhook、节点实际安装/下发和第三方插件任意 JavaScript 不在隔离验证范围。插件声明式菜单/配置/CRUD 可用，自定义 JavaScript 页面仍按既有边界不执行。开发环境巡检只读，不以真实用户或节点做破坏性验收。
